## Исходный проект

В проекте уже реализованы:

- интерфейс `BaseAnalogClock`;
- класс `AnalogClock`, хранящий время как положение стрелок и признак `AM/PM`;
- интерфейс `BaseDigitalClock`, с которым должен работать клиентский код;
- `ClockFormatter` для форматирования времени;
- `ClockHistory` для хранения истории установленных значений;
- пример клиентского компонента `DigitalClockDisplay`.

## Важное требование

Adapter и Facade решают разные задачи.

- **Adapter** преобразует один интерфейс в другой.
- **Facade** предоставляет более простой интерфейс к подсистеме.

Не следует объединять их в один класс только потому, что оба используются в одной лабораторной работе.

## Описание решения

В данной лабораторной работе реализованы два структурных паттерна проектирования: **Adapter (Адаптер)** и **Facade (Фасад)**.

### 1. Реализация паттерна Adapter

Для реализации паттерна Adapter создан класс `DigitalClockAdapter`, который наследуется от интерфейса `BaseDigitalClock` и использует существующий класс `AnalogClock`.

Основная задача адаптера — обеспечить совместимость цифрового и аналогового представления времени.

Класс выполняет следующие преобразования:
- получает дату и время в формате `datetime`;
- извлекает год, месяц, день, часы, минуты и секунды;
- определяет часть суток (AM или PM);
- преобразует часы, минуты и секунды в углы соответствующих стрелок аналоговых часов;
- при получении данных выполняет обратное преобразование в объект `datetime`.

Для преобразования времени используются следующие формулы:

- Угол часовой стрелки: `30 * hour + 0.5 * minute + second / 120`.
- Угол минутной стрелки: `6 * minute + 0.1 * second`.
- Угол секундной стрелки: `6 * second`.

Таким образом, адаптер позволяет использовать аналоговые часы через цифровой интерфейс без изменения исходного класса `AnalogClock`.

### 2. Реализация паттерна Facade

Для реализации паттерна Facade создан класс `ClockFacade`, который объединяет взаимодействие нескольких компонентов системы и предоставляет единый интерфейс для работы с ними.

Фасад использует три компонента:
- `DigitalClockAdapter` — отвечает за установку и получение даты и времени;
- `ClockFormatter` — выполняет форматирование даты и времени;
- `ClockHistory` — хранит историю установленных значений даты и времени.

Класс `ClockFacade` предоставляет следующие методы:

- `set_date_time()` — устанавливает дату и время, а также добавляет их в историю изменений;
- `get_date_time()` — возвращает текущую дату и время;
- `get_formatted_time()` — возвращает дату и время в заданном формате;
- `get_history()` — возвращает историю изменений.

Использование фасада упрощает взаимодействие с системой, так как клиентской программе не требуется самостоятельно создавать и вызывать каждый компонент.

### 3. Тестирование

Для проверки корректности работы разработаны автоматические тесты с использованием pytest.

**Тестирование адаптера:**
- проверка преобразования даты и времени в углы аналоговых часов;
- проверка обработки граничных значений времени: полуночи и полудня.

**Тестирование фасада и истории изменений:**
- проверка установки и получения даты и времени;
- проверка стандартного форматирования;
- проверка пользовательского формата времени;
- проверка сохранения нескольких изменений в истории;
- проверка пустой истории при создании фасада.
